# Edgar Andrés Delgado — CV

Personal CV website of **Edgar Andrés Delgado Castellano**, ICT Solutions Analyst · IT Systems & Operations, Melbourne VIC.

**Live:** https://andresdelgado15.github.io/CV/

## About this site

- Hand-written HTML, CSS and vanilla JavaScript; no frameworks or build step.
- Responsive and accessible (semantic HTML, keyboard focus styles, reduced-motion support).
- Privacy-first: no analytics or tracking cookies. The contact form uses Formspree and requires explicit consent; see [`privacy.html`](privacy.html).
- Downloadable PDF CV in [`assets/Edgar-Delgado-CV.pdf`](assets/Edgar-Delgado-CV.pdf).

## Structure

```
index.html         CV page
privacy.html       Privacy policy (Australian Privacy Principles)
assets/style.css   Styles
assets/main.js     Contact form and scroll reveal
assets/            Photo and PDF CV
```
